# eu_gestão - Gestão de Processos de TI

Repositório dedicado à estruturação, planejamento e monitoramento de demandas de tecnologia e processos.

## Objetivo

- Mapear o ciclo de vida completo de cada demanda
- Estimar prazos realistas com base na complexidade
- Antecipar falhas e criar planos de contingência
- Analisar impacto sistêmico e departamental
- Gerar relatórios executivos para a diretoria

## Estrutura

```
eu_/
├── demandas/          # Registro de demandas e projetos
├── relatorios/        # Relatórios executivos (Word/Excel)
├── processos/         # Documentação de processos
├── templates/         # Templates reutilizáveis
└── docs/              # Documentação geral
```

## Status

Projeto em estruturação inicial.
